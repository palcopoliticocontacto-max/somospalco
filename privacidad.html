Política de privacidad

Última actualización: 16 de noviembre de 2026

Esta política explica cómo trata los datos la aplicación Fábrica de vídeos somospalco (en adelante, «la aplicación»).

1. Qué es la aplicación

Es una herramienta interna que usa únicamente el titular de somospalco para publicar sus propios vídeos en sus propias cuentas de YouTube, Instagram y TikTok. No está abierta al público, no tiene usuarios registrados y no ofrece servicios a terceros.

2. Qué datos usa

  • YouTube (Google): el permiso para subir vídeos al canal de somospalco y para consultar el estado de esos vídeos (si se han publicado y su enlace).
  • Instagram (Meta): la información básica de la cuenta profesional de somospalco y el permiso para publicar contenido en ella.
  • TikTok: la publicación se hace a través de Buffer, con la cuenta de Buffer del titular.

La aplicación no accede a datos de otras personas: ni seguidores, ni comentarios, ni mensajes, ni información de terceros.

3. Para qué los usa

Solo para publicar los vídeos de somospalco a la hora programada y comprobar que la publicación se ha completado.

4. Dónde se guardan

Los permisos de acceso (tokens) se guardan cifrados en los secretos de GitHub Actions de un repositorio privado del titular. No se guardan en ningún otro lugar ni se muestran públicamente.

5. Con quién se comparten

Con nadie. Los datos no se venden, no se ceden ni se usan con fines publicitarios. Solo se envían a las plataformas indicadas (Google, Meta y Buffer) para publicar el contenido.

El uso y la transferencia de la información recibida de las APIs de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

6. Cómo retirar los permisos

  • Google / YouTube: myaccount.google.com/permissions
  • Instagram: Configuración → Apps y sitios web
  • Buffer: desconectando el canal desde la cuenta de Buffer

Al retirarlos, los tokens guardados dejan de funcionar y se eliminan.
